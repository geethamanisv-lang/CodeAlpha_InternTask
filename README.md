## Projects Included

### 1. Hangman Game
**Description:** A simple word-guessing game where the player tries to guess a hidden word by entering one letter at a time.

**Key Concepts Used:**
- Python strings
- Lists
- Loops
- Conditional statements
- User input and output

### 2. Stock Portfolio Tracker
**Description:** A simple Python application that calculates the total investment value based on user-entered stock names and quantities using predefined stock prices.

**Key Concepts Used:**
- Dictionaries
- Variables
- Loops
- Conditional statements
- User input and output
- File handling

### 3. Basic Chatbot
**Description:** A simple rule-based chatbot that interacts with users and provides predefined responses based on their messages.

**Key Concepts Used:**
- Functions
- If-elif-else statements
- While loops
- String methods
- User input and output

## How to Run the Projects

1. Clone or download this repository.
2. Open the project folder in your Python editor.
3. Run the respective Python file.

Example:

```bash
python hangman.py
python stock_tracker.py
python chatbot.py
```
